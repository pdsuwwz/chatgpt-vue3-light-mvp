# 迁移检查清单

在其他项目实现类似聊天产品前，使用这份清单检查方案。

## 产品范围

- 决定是单轮对话还是多轮对话。
- 决定推理内容是展示、隐藏，还是折叠展示。
- 决定回答是否需要 Markdown、代码复制、数学公式和 Mermaid。
- 决定模型切换是用户可见，还是仅配置可见。

## 技术边界

- 定义适配器契约。
- 先增加 Mock Stream 适配器。
- 不要在 UI 组件中解析供应商响应。
- 不要把流式拆包逻辑混在供应商请求代码里。
- 不要让模型适配器负责 Markdown 渲染。

## 运行时与安全

- 生产环境使用后端或代理保护 API Key。
- 明确本地开发的 CORS 和代理行为。
- 支持请求停止。
- 在停止、失败和完成后重置 parser 状态。
- 处理供应商限流、排队或 keep-alive 消息。

## UI 行为

- 流式生成中禁用提交，或把提交按钮切换为停止按钮。
- 完成或失败后恢复输入框焦点。
- 网络完成后继续刷完 display buffer。
- 只有用户接近底部时才自动滚动到底部。
- 提供空状态、等待中、流式生成中、已完成、失败、已停止状态。
- 支持复制完整回答和代码块。

## 渲染验证

- 纯文本流可以增量渲染。
- OpenAI 兼容 SSE 可以正确渲染。
- JSON-line 流可以正确渲染。
- 推理内容可以干净地开始和结束。
- Markdown 列表和表格可以正确渲染。
- 代码块包含语言标签和复制动作。
- KaTeX 行内和块级公式可以正确渲染。
- Mermaid 图表可以在增量更新后渲染。
- 在纯文本、代码块、数学公式和 Mermaid 输出过程中停止生成都能正常工作。
